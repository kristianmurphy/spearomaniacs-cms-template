CMS TEMPLATE - START HERE
=========================

This folder is the SANITY CONTENT STUDIO. It runs at http://localhost:3333.
The separate spearomaniacs-template folder is the WEBSITE. It runs at
http://localhost:3000.

IMPORTANT
---------
Use the new owner's Sanity project. Never use the Spearomaniacs production project ID
5v60gbu6, or this template will stop with a safety error.

1. FILL IN THE CMS SETTINGS
---------------------------
If this folder came from GitHub, first run:

cp .env.example .env.local

Then open .env.local in this folder and fill in:

SANITY_STUDIO_TITLE=TYPE_THE_BRAND_NAME_HERE CMS
SANITY_STUDIO_PROJECT_ID=PASTE_NEW_PROJECT_ID_HERE
SANITY_STUDIO_DATASET=production
SANITY_STUDIO_STOREFRONT_URL=http://localhost:3000

Leave SANITY_STUDIO_APP_ID blank for the first deployment. Sanity can create it during
deployment. Do not put spaces around the equals sign, except inside the title value.

The project ID here must exactly match NEXT_PUBLIC_SANITY_PROJECT_ID in the website's
.env.local file.

2. INSTALL AND START THE CMS
----------------------------
Open Terminal in this folder and run:

npm install
npx sanity login
npm run dev

Open http://localhost:3333 and publish the Site Settings content.

If Terminal says sanity: command not found, npm install was not completed in this folder.
Use npx sanity login, not sanity login.

3. DEPLOY THE CMS TO SANITY
---------------------------
From this folder run:

npm run deploy

Choose a unique hostname when prompted. Sanity will provide a URL ending in
.sanity.studio. If deployment adds an app ID, place it in .env.local like this:

SANITY_STUDIO_APP_ID=PASTE_APP_ID_HERE

4. SECURITY CHECK
-----------------
Before editing anything, confirm the project shown in Sanity belongs to the new owner.
The CMS and website must both use the same new project ID, not 5v60gbu6.

Never commit .env.local or put Sanity write tokens, Printful tokens, Stripe keys, or email
service keys in this CMS. Those server secrets belong only in the website environment.
